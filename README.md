# AI人工智慧導論期末個人專題 YOLO 視覺辨識
​這套系統擺脫了傳統單一色彩過濾容易誤判的缺點，結合了 AI 深度學習、剛體幾何學、色彩學優化 與 動態圖層遮罩，分為四大核心模組：
​🔹 模組一：低飽和度抗過曝 HSV 色彩過濾器 (check_red_light)
​技術痛點： 競賽現場的高亮度 LED 得分燈在相機鏡頭下會產生「曝光過度 (Overexposure)」，導致 LED 核心區域在色彩空間中呈現飽和度極低的「純白色」。傳統 HSV 設定（如 S > 100）會完全無法捕捉這類強光。
​實作解法： 將飽和度門檻下修至 S \ge 30、明度門檻設為 V \ge 150。藉由 capture 泛白核心外圍的紅光擴散暈（Halo），顯著提升強光環境下的偵測召回率（Recall）。
​🔹 模組二：YOLO26 剛體特徵與幾何向量盲推
​技術痛點： 靶板下排的洞口容易被場上其他障礙物或敵方機器人擋住，導致無法直接辨識。
​實作解法： 僅需抓取頂部三個未被遮擋的 TEL 剛體標籤。利用三個標籤的座標建立基準底向量 \vec{u} = (ux, uy) 與法向量 \vec{d} = (-uy, ux)，並結合高比例係數（ROW_RATIOS），在 2D 影像平面上隔空精準逆解出 12 個孔洞的相對空間座標。
​🔹 模組三：動態幾何孔洞遮罩 (Dynamic Geometry Mask)
​技術痛點： 現場環境複雜，靶板印刷紅邊、裁判紅衣服或背景紅色雜訊容易造成 HSV 誤判。
​實作解法： 活用模組二推算出的 12 個孔洞座標，即時在背景畫布上生成帶有 12 個白色圓圈（半徑 20px）的動態遮罩 dynamic_hole_mask。透過 cv2.bitwise_and 位元運算，將 12 個得分格以外的所有畫面強制塗黑，實現 100% 區域隔離的極致抗噪。
​🔹 模組四：戰術 HUD 與雙視窗即時雙向監控
​主視窗 (Robot Vision HUD)： 繪製鋼鐵人風格的戰術 HUD，即時疊加中央準心、YOLO 盲推綠色準心、得分格紅色狙擊框，以及動態火控狀態標籤（READY TO FIRE / FIRE CONTROL HOLD），方便操作員進行戰術決策。
​除錯視窗 (HSV Red Mask View)： 輸出經過動態遮罩過濾後的黑白二值化影像，現場僅會呈現亮紅燈處的白色色塊，提供現場調校 HSV 門檻時最直觀的視覺反饋。
